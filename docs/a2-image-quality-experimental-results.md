## 2. 재현 조건과 데이터 분리

```bat
conda activate vision-insight
python -B scripts/experiments/run_quality_experiments.py --output data/outputs/quality-analysis/a2-experiments-새고유이름
```

출력은 기존에 존재하지 않는 새 폴더만 허용한다. A-1의 `a1-baseline-20261020-verified/results.json`이 기본 입력이다.

기존 입력/출력 덮어쓰기 없이 Python `-B`, OpenCV1스레드, NumPy 고정 난수 seed20261020을 사용했다.
정확한 라이브러리 버전·파라미터·A-1 SHA256은 `experiment-config.json`에 저장했다.

실험값은 측정 전에 고정했다: 중심창96px, 상대 중심 각 축50%, Gray207, 고휘도245/250/254,
blur sigma1/2, gain0.5, contrast0.5, clipping gain1.8, JPEG80, noise sigma2, 절반 해상도.
Gray207은 A-1 탐색 마스크를 재사용한 것이며 촬영 품질 정상/불량 임계값이 아니다. 결과를 보고 파라미터를 재조정하지 않았다.

같은 제작 원본 해시, 같은 Capture, 같은 PNG 해시로 연결되는 표본은 전이적으로 같은 그룹에 묶었다.
영상 제작 매니페스트와 기존 렌더링 배치의 bbox 중첩을 보수적으로 사용했고, 중첩한 원본 후보가 여러 개면 그룹을 합쳤다.
원본 후보를 확인할 수 없으면 미확정 표본끼리 같은 그룹으로 묶도록 구현했다. 원본 정답 라벨은 읽거나 출력하지 않는다.

- 개발 구간: **6개 원본 연결 그룹/44개 Crop**.
- 확인용 구간: **4개 그룹/16개 Crop**.
- 같은 Crop의 모든 변형은 같은 구간에 남는다. 집계는 이미지별 비율뿐 아니라 **원본 그룹별 중앙값의 중앙값**을 기록한다.
- 이는 같은 두 합성 영상 안의 내부 분리이며, 실카메라·독립 제품·정답 라벨 기반 외부 검증이 아니다.
- bbox 기반 원본 대응은 제작 코드에 따른 보수적 추정이다. 이미지 정합 정답이나 물리적 제품 추적 정확도로 주장하지 않는다.

## 3. 측정 구현

`quality_candidates.py`는 측정값과 실패 상태만 반환한다. 새 quality_status/final_result를 생성하지 않는다.

| 계열 | 지표/처리 |
|---|---|
| 밝기 | mean, median, std, P10/P25/P75/P90, GV<125, GV≥200, P90−P10 |
| 위치 | 각 축 중앙50% 영역(면적 약25%), 나머지 가장자리, 고정 중앙96×96 원본 픽셀창 |
| 전경/배경 | A-1 닫힌 Gray207 외곽 후보를 재사용. 경계 접촉·작은 성분·큰 성분 다수이면 실패/null |
| 선명도 | Laplacian variance, Tenengrad, 각각을 Gray variance로 나눈 후보 |
| 포화/대비 | GV≥245/250/254 비율, 연결 성분 수/최대 면적/경계 접촉, 성분 내부std·국소std, 주변 Sobel 경계, 5×5 국소std |

Laplacian/Sobel은 ksize3, CV_64F다. 미분은 원본 이미지에서 계산한 후 마스크로 선택하며 검은 마스크 경계를 추가하지 않는다.
Gray variance가0이면 정규화 결과는null이다. 극저대비에서 정규화 지표의 통계적 신뢰성이 확보된다는 뜻은 아니다.
정상 입력은 uint8 BGR/Gray, 최소3×3이다. NaN/Inf/잘못된 채널/작은 입력/잘못된 ROI는 명시적 ValueError로 거부하며 임의 보정하지 않는다.
마스크 수치 confidence는 도입하지 않고 미보정 상태로 표시한다. 미검출 외곽을 원으로 채우지 않는다.

실제 motion blur·초점 이탈·광학적 저노출의 정답이 없으므로 실환경 분리 성능은 NOT VERIFIED다.

## 6. 포화·흰 배경·반사 후보

## 10. A-3 승인 전에 필요한 결정

1. **계측만 할지 여부:** 두 추천 후보를 별도 shadow 기록으로 먼저 적용할지 결정한다. 기존 quality/final_result는 그대로 둔다.
2. **검사 영역 계약:** 중심창 위치/크기·원본 스케일·병 포함 여부를 어떻게 검증할지 정한다. 고정96창은병 내부만 볼 수 있으므로 림 품질의 충분 조건이 아니다.
3. **평가 자료:** 실제 초점 이탈/motion blur/저노출/정상 반사/과노출 자료에 촬영 품질 라벨을 확보한다. 제품 결함 라벨과 분리하고 원본별 그룹을 유지한다.
4. **실패 규칙:** 마스크 실패·무대비·저대비·잘림·미지원 스케일의 계측 상태와 화면 설명을 정한다. 경고/REINSPECT 연결은 별도 승인이다.
5. **수락 기준:** 품질 라벨에 대한 오수락/오경고·판단 보류·그룹별 안정성 기준을 데이터 확보 후 사전 정의한다. 이번 합성 비율로 품질 threshold를 확정하지 않는다.
6. **기존 데이터:** 과거 검사/판정은 재계산·덮어쓰기하지 않는다. 운영schema 추가가 필요하면 변경 계약부터 승인받는다.
