## 2. 데모 실행 방법 (발표 PC 환경)

### A. 일반 브라우저로 실행 (추천)
인터넷 연결이 없는 환경에서도 Chrome, Edge, Safari, Firefox 등 모든 최신 웹 브라우저에서 더블 클릭하여 바로 실행할 수 있습니다.

```powershell
# Windows PowerShell 예시
Start-Process "presentation\demo\t01-report-demo.html"
```

### B. 발표자 편의 기능 활용
1. **발표 시연 흐름 (Tour Chips):**
   - 화면 상단의 `[전체 개요]`, `[1. PatchCore 검사]`, `[2. 판정 규칙]`, `[3. Gemini 진단 요약]`, `[4. Evidence 검증]`, `[5. 권장 조치 및 한계]` 칩을 클릭하면 해당 섹션으로 부드럽게 스크롤되며 하이라이트 박스가 켜집니다.
2. **Evidence 추적 인터랙션:**
   - 권장 조치 카드 내의 **`근거 참조 (evidence_refs): ["F0003"] ➔`** 버튼을 클릭하면, 하단 관측 사실 테이블의 `F0003 (/data/final_result = "OK")` 행이 자동으로 하이라이트됩니다.
   - 관측 사실 테이블의 각 행을 직접 클릭해도 해당 팩트와 서버 부여 `E0001`의 검증 상태가 토스트 팝업으로 안내됩니다.
3. **폰트 확대/축소:**
   - 빔 프로젝터나 대형 모니터 환경에 맞춰 상단 우측의 `A+`, `A-`, `기본` 버튼으로 폰트 크기를 실시간 조절할 수 있습니다.
4. **테마 전환:**
   - 발표장 조명에 따라 `🌙 테마 전환` 버튼으로 고대비 인더스트리얼 다크 모드와 클린 라이트 모드를 즉시 전환할 수 있습니다.
5. **데모용 주요 필드 JSON 복사:**
   - `📋 데모용 주요 필드 JSON 복사` 버튼을 누르면 데모 렌더링에 사용된 핵심 필드 축약 JSON 데이터(`t01DemoJson`)가 클립보드에 복사됩니다. (전체 원본 응답이 아닌 데모용 축약 객체임을 명시)

## 3. 오프라인 작동 및 데이터 안전성 보장

1. **외부 CDN 의존성 0건:**
   - Tailwind CDN, Google Fonts, 외부 아이콘 웹폰트, 외부 이미지를 일체 포함하지 않습니다.
   - 모든 CSS 스타일, 인라인 벡터 SVG 아이콘, 폰트 폴백 스택, JavaScript 로직이 `t01-report-demo.html` 파일 내부에 100% 임베딩되어 있습니다.
   - 비행기 모드나 폐쇄망 환경에서도 완벽히 동일한 디자인으로 동작합니다.
2. **실제 Gemini 유료 API 호출 0회:**
   - 화면에 명시된 안내문: `"저장된 T01 실제 검증 결과를 재생한 발표용 정적 데모입니다. 현재 Gemini API를 호출하지 않습니다."`
   - 발표 중 외부 네트워크 지연(HTTP 504)이나 과금 리스크가 전혀 발생하지 않습니다.
3. **금지된 표현의 철저한 배제:**
   - ❌ 실시간 검사 진행 중
   - ❌ 현재 Gemini 분석 중
   - ❌ 물리적 카메라 연결 중
   - ❌ 공장 설비 운영 중
   - ❌ 모든 불량 검출 성공
   - ❌ Gemini가 결함의 실제 정답을 판단함
