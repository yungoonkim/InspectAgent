## 2. 데모 실행 방법 (발표 PC 환경)

### A. 일반 브라우저로 실행 (추천)
인터넷 연결이 없는 환경에서도 Chrome, Edge, Safari, Firefox 등 모든 최신 웹 브라우저에서 더블 클릭하여 바로 실행할 수 있습니다.

```powershell
# Windows PowerShell 예시
Start-Process "presentation\demo\t03-report-demo.html"
```

### B. 발표자 인터랙션 기능
1. **발표 시연 흐름 (Tour Chips):**
   - 상단 칩 네비게이션: `[전체 개요]`, `[1. PatchCore 검사 (OK)]`, `[2. 판정 규칙 (Rule 2 ➔ REINSPECT)]`, `[3. Gemini 진단 요약]`, `[4. Evidence 검증 (F0001~F0012)]`, `[5. 가설 & 재검사 권고]`
   - 클릭 시 해당 카드 섹션으로 부드럽게 스크롤되며 하이라이트 테두리가 켜집니다.
2. **Evidence 추적 인터랙션 (실제 T03 Fact 매핑):**
   - 권장 조치 카드의 **`근거 참조: ["F0004", "F0007"] ➔`** 클릭 ➔ 조도 저하 팩트 행이 즉시 하이라이트됩니다.
   - 권장 조치 카드의 **`근거 참조: ["F0003"] ➔`** 클릭 ➔ 최종 REINSPECT 판정 팩트 행이 즉시 하이라이트됩니다.
   - 관측 사실 테이블의 개별 행(`F0001`~`F0012`)을 직접 클릭해도 상세 JSON Pointer 및 검증 상태가 토스트 팝업으로 표시됩니다.
3. **폰트 확대/축소 및 테마 전환:**
   - 빔 프로젝터 환경을 위한 `A+`, `A-`, `기본` 폰트 크기 조절 기능.
   - `🌙 테마 전환` 버튼으로 고대비 인더스트리얼 다크 모드와 클린 라이트 모드를 즉시 전환 가능.
4. **데모용 주요 필드 JSON 복사:**
   - `📋 데모용 주요 필드 JSON 복사` 버튼 클릭 시 데모 화면에 바인딩된 핵심 정제 객체(`t03DemoJson`)가 클립보드에 복사됩니다.

## 3. 오프라인 작동 및 데이터 안전성 보장

1. **외부 CDN 의존성 0건:**
   - Tailwind CSS, Google Fonts, 외부 SVG 라이브러리를 일체 사용하지 않습니다.
   - CSS 변수 기반 다크/라이트 테마, 인라인 벡터 SVG 아이콘, 바닐라 JavaScript가 단일 파일 내에 100% 임베딩되어 있습니다.
2. **실제 Gemini 유료 API 호출 0회:**
   - 상단 배너 고지: `"저장된 T03 실제 Gemini E2E 성공 결과를 재생하는 발표용 정적 데모입니다. 현재 Gemini API를 호출하지 않습니다."`
   - 발표 중 외부 네트워크 지연이나 추가 과금이 일체 발생하지 않습니다.
3. **엄격한 기술적 표현 원칙 준수:**
   - ❌ 실시간 AI 검사 진행 중
   - ❌ 실제 공장 카메라 연결 중
   - ❌ 실제 공장 PLC, 배출기, 컨베이어 제어 완료 (`REINSPECT`는 서버의 최종 검사 판정값이며, 실제 물리적 제품 선별이나 배출기 제어는 수행하지 않음)
   - ❌ Gemini가 REINSPECT 판정을 내림 (FastAPI 서버 규칙 계층이 판정)
   - ❌ Gemini가 제품 불량을 발견함 (외관 이상치는 임계값 미만 모델 OK였으며 영상 품질 경고 반영)
   - ❌ 조명 고장을 확인함 (조명 이상은 '가능성 가설'로만 명시, 물리적 고장 미확인 고지)
   - ❌ 산업용 진단 표준 구현 / 모든 환경 변화에 대응 가능 (근거 기반 진단 프로토타입으로 한정)
   - ❌ 30초 timeout으로 504 원인을 완전히 해결함 (이전 15초 timeout 시 약 14.15초 소요 실패의 내부 원인은 UNKNOWN이며, 30초 설정 단일 회차의 18.967초 성공으로 향후 안정성을 보장하지 않음)
